### ACTIVIDAD 02 — Elegir el sistema a transferir


1. Sistema elegido

El sistema elegido fue el de partículas y motion systems basado en trayectorias y movimiento procedural.

2. Cómo funcionaba en p5.js

En p5.js los sistemas de partículas funcionaban mediante objetos que almacenaban propiedades como posición, velocidad y dirección. Estos sistemas permitían generar movimiento continuo y comportamientos dinámicos utilizando fuerzas, trayectorias y variaciones en el tiempo.

3. Por qué decidí transferirlo

Decidí transferir este sistema a Blender porque Geometry Nodes permite recrear comportamientos procedurales similares dentro de un entorno tridimensional. Además, permite combinar trayectorias, simulaciones y movimiento procedural con iluminación y render cinematográfico.

4. Tipo de pieza visual

La pieza visual consiste en una escena espacial procedural donde un cohete realiza una trayectoria orbital alrededor de Saturno mientras genera una estela dinámica similar a un sistema de partículas. Paralelamente, el planeta posee un sistema de anillos animados mediante movimiento oscilatorio y escalado procedural.

5. Dificultades técnicas anticipadas
Comprender la lógica procedural dentro de Geometry Nodes.
Controlar trayectorias y movimiento continuo.
Ajustar correctamente el comportamiento visual de las partículas y estelas.
Integrar diferentes animaciones dentro de una sola escena manteniendo coherencia visual.

Qué resolvió

#### ACTIVIDAD 04 — Estudio de transferencia



p5.js	Blender Geometry Nodes
Sistemas de partículas	Trails y geometría procedural
Movimiento basado en código	Movimiento basado en nodos y trayectorias
Variables de posición y velocidad	Paths, curvas y animación procedural
Simulación 2D	Simulación 3D
Render simple	Render cinematográfico
Qué se mantiene
La lógica procedural.
El movimiento continuo.
El comportamiento dinámico.
La idea de partículas y trayectorias.
Qué cambia
El sistema pasa de 2D a 3D.
La lógica se construye mediante nodos y animaciones.
Se incorpora iluminación y render cinematográfico.
Ventajas
Mayor calidad visual.
Posibilidad de crear escenas cinematográficas.
Integración de materiales, luces y cámaras.
Limitaciones
Mayor complejidad técnica.
Requiere más procesamiento.
Los sistemas proceduralmente complejos pueden ser difíciles de optimizar.
¿Qué aprendí?

Aprendí que los principios vistos en p5.js pueden trasladarse a otros entornos aunque cambie la herramienta. También comprendí que el proceduralismo no depende únicamente del código, sino de la lógica de sistemas, trayectorias y comportamiento dinámico.
